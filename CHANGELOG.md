# Changelog

## [1.0.0] — 2026-10-19

- First public release of the unofficial RunCat Neo × macwatt bridge.
- Three live power measurements (input, battery, system) and negotiated adapter specs.
- Poll once per 5 seconds; only rewrite Custom Metrics JSON when shown values change.
- One user-level `launchd` agent, no additional menu-bar icon.
- Offline installation with bundled MIT-licensed macwatt source and original license.
- Preserve the JSON source path across earlier v2/v3 upgrades.
- English and Korean documentation, unit tests, GitHub Actions CI and release ZIP.
